# 实验实现状态

固定样本90,750条评论、1,000个ASIN；评论对基准为6,000对（训练4,000、验证1,000、测试1,000）。按商品划分，并隔离跨集合相同规范化正文。标签由自动辅助判读生成，尚未经过独立人类标注者验证。

## 已完成

- 数据版本固定、稳定编号、异常及三种重复口径审计。
- 6,000对正文判读与边界复核；确定训练标签2,258对，其中重复185对、非重复2,073对。
- 2,000个合成训练正例及100个变换检查；合成权重占合并训练权重20%。
- 规范化精确匹配、字符TF-IDF、词面逻辑回归、固定MiniLM语义向量、词面加语义逻辑回归五种方法。
- 验证选型、模型与阈值锁定、一次封存测试。测试确定标签705对，不确定295对。
- 38项工程检查通过；夹具结果不代表真实模型效果。

## 实测结论

没有方法满足预设的验证精确率95%及至少30个正预测要求。词面逻辑回归与加入语义特征的逻辑回归在锁定测试配置下结果一致：确定标签上精确率66.67%、召回率4.55%，仅3个正预测。单独语义阈值的精确率9.49%、召回率34.09%。这些是固定富集参考标签集的探索结果，不能外推为自然重复率或自动降权效果。

全量1,000商品内部4,146,325对推断已完成，生成20,731,625方法行（压缩结果约570MiB）；10商品交接样例、汇总报告和结果图已生成。数据编号、划分、配对、缓存及全量输出溯源等9项实际验收全部通过；本地审计notebook的6个代码单元执行完成，无错误。全部输出保留待复核标记，不生成降权权重或传递重复组。最终报告位于experiment_results.md，执行及接口说明见runbook.md。

研究对象是文字信息冗余，不能据相同措辞推断评论者真实性。抽样限制及标签定义见data_audit.md与annotation_guide.md。数据、标签、模型和CSV/JSON结果保留本地。

固定模型已使用28条公开中文样例的112个同源变换、46个构造控制对及其46个英文对照进行诊断。中文词面覆盖及按空格计词存在适配问题，否定与数字辨别在英文中也有误信号。目前不宜把既有模型/阈值直接用于中文近似重复或自动评分降权；原交接包及英语结果没有修改。测试规模与实际分组结果见[中文诊断报告](chinese_probe.md)。
